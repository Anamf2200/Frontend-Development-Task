# 🚛 DispatchPro – Truck Dispatch Website

DispatchPro is a responsive multi-page website built for a truck dispatch company.  
It is developed using **HTML5, CSS3, Bootstrap 5, and JavaScript** for form validation and UI interactions.

---

## 🌐 Live Pages

- Home Page
- Services Page
- Contact Page

---

## 📌 Project Overview

This project is designed to simulate a real-world trucking dispatch company website.  
It focuses on clean UI design, responsiveness, and user-friendly experience.

---

## 🛠️ Technologies Used

- HTML5 (Semantic Structure)
- CSS3 (Custom Styling)
- Bootstrap 5 (Responsive Layout)
- JavaScript (Form Validation & UI Interaction)
- Font Awesome (Icons)
- Google Fonts (Typography)

---

## ✨ Features

### 🏠 Home Page
- Responsive navigation bar
- Hero section with introduction
- Company statistics section
- Why Choose Us section
- Call-to-action section
- Professional footer

### 🚚 Services Page
- Truck dispatch services listing
- Route planning services
- Load management system
- Driver support services
- Modern Bootstrap service cards

### 📞 Contact Page
- Contact form with real-time validation
- Success message on submission
- Company contact details
- Google Maps embedded section
- Social media integration

---

## ⚙️ JavaScript Features

- Real-time form validation
- Name, email, phone, and message validation
- Character counter for message box
- Success message animation
- Button loading effect on submit
